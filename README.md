# 포챔스 달콤아 봇

챔피언스 전용 로컬 통계 스냅샷 기반 파티 빌더. 모든 추천은 sources의 사용자 제공 마스터 목록과 모드별 통계 교집합으로 제한한다.

## 현재 구현
- 싱글/더블 각각 235종 전체 인덱싱 및 검색
- 여섯 슬롯 편집, 개별 채용률 확인, 팀메이트 기반 후보 추천
- 중복 도구, 미완성 세팅, 능력 배분 범위 검증
- 모드별 브라우저 저장, 검증 후 JSON 가져오기/내보내기
- 한국어 브라우저 OCR: 참고 2열 3행 화면을 슬롯별로 잘라 Tesseract와 현재 235종 이미지 DB를 함께 비교. 능력/스테이터스 결과 합치기 및 수동 확인
- 웹과 디스코드 계산기: 두 포켓몬만 선택하는 결정력 7개 내구 기준 일괄 계산과 최속·준속·무보정·스카프 스피드 비교. 상세 `/계산기`에서는 기술과 배분을 직접 선택

## 데이터 계약
추천 세팅은 각 포켓몬의 해당 모드 통계에 나타나야 한다. 능력 배분은 6개 정수, 각 0~32, 총합 66 이하이다. 사용자가 수동 편집한 배분은 범위 검증을 거쳐 저장 가능하나 통계 추천으로 주장하지 않는다. 개별 세팅 비율은 완성 세트의 동시 채용률이 아니다.

마스터 표기는 사용자가 제공한 명칭을 유지한다. 한국어 정식 표기에 대한 전체 외부 검증은 아직 미완료이다. 일본어·숫자 식별자 등 122개 항목은 sources/quarantine.json에 격리한다. 외부 게임의 데이터나 번역 사전을 섞지 않는다.

카운터 열은 원본의 “이 포켓몬을 쓰러뜨린 포켓몬” 통계로 사용한다. 파티 점검에서는 선택 멤버를 쓰러뜨린 상대를 표시하고, 추천에서는 해당 상대를 다시 쓰러뜨린 기록을 역방향으로 찾아 실전 대응 근거로 반영한다. 승률 예측으로 해석하지 않는다.

## 제한 및 검증
- 현재 데이터는 2026-07-14 M-4. 최신 시즌으로 표시하지 않는다.
- OCR 엔진과 한국어 파일은 사용 시 CDN에서 내려받으며 네트워크 접근이 필요하다.
- 별명 화면은 현재 235종의 폼별 기본 이미지, 제공받은 챔피언스 화면 조각, 통계 교집합을 함께 비교하고 적용 전에 사용자 확인을 받는다.
- 능력치 화면의 성격은 자동 확정하지 않는다.
- 470행 화이트리스트, 채용률 범위, 전체 통계 배분, OCR 숫자 파서 경계 검사를 통과했다.
- 제공받은 선출 화면 중 윤곽을 확인할 수 있는 세 장을 36개 화면 조각으로 등록했다. 극저화질 두 장은 오학습을 막기 위해 기준 DB에는 넣지 않고 실패 안전성 확인용으로만 사용한다.

## 추가 연결

champs.pokedb.tokyo 오픈데이터 안내를 확인하여 M-4 상위 파티를 캐시 파일로 연결했습니다. 싱글 223개, 더블 31개, 원문 갱신 2026-08-19입니다. `scripts/import_opendata.py`가 이름 대응표 및 모든 항목을 검증하고 `dist/opendata.json`을 생성합니다. `scripts/parse_snapshot.py`는 첨부 상세 통계 전체를 재생성합니다. 화면의 상위 파티 표본 비율과 상세 세팅 통계는 다른 모집단입니다.

AWS 이전용 CloudFormation, 수집 Lambda, 배포 스크립트는 `aws/`에 있습니다. 디스코드 슬래시 명령 핸들러와 등록 스크립트는 `discord/`에 있습니다. 웹과 봇은 `dist/engine.mjs`의 동일 추천/검증 함수를 사용합니다. 실제 계정 배포·설치는 아직 하지 않았습니다.

검증: `node tests/verify.mjs` — 470종 모드별 통계, 254개 공개 파티, 표본 채용률 분모, 공유 추천, 배분 경계, 숫자 OCR 파서, Discord 서명 및 명령 응답 검증 통과.

## 2차 수정

- OCR 엔진, Worker, WASM, 한국어/영어 모델을 같은 앱에서 제공하도록 변경했습니다. 외부 CDN 로딩에 의존하지 않습니다.
- 업로드 후 자동 인식, 초기화·인식 제한 시간, 슬롯별 진행, 명확한 오류 메시지를 제공합니다.
- 스테이터스는 여섯 숫자 영역을 따로 인식하고 필요한 경우 배분 숫자만 재인식합니다. 참고 스테이터스의 36개 배분 값에 대해 실제 OCR 결과를 확인했습니다. 브라우저 화면에서의 E2E 검사는 수행하지 않았습니다.
- 후보 버튼을 누르면 선택되고, 슬롯별 이름 검색으로 원하는 포켓몬을 고를 수 있습니다.
- 카드·추천·메타·공개 파티의 포켓몬 이름에서 상세 통계 창을 엽니다. 첨부 자료의 모든 유효한 기술·도구·특성·성격·배분·팀메이트·쓰러뜨린 포켓몬 항목을 보여 줍니다. 팝업 바깥 영역을 누르면 닫힙니다.
- 원본 팀메이트 1~10위를 별도 후보 목록으로 표시하며, 여러 멤버를 선택하면 연결 수와 원본 순위를 합산합니다. 종합 추천에도 팀메이트 근거를 최대 20점 반영합니다.
- 공유 추천 엔진은 타입 보완 30점, 상위 표본 메타 타입 대응 30점, 쓰러뜨린 포켓몬의 역방향 실전 대응 25점, 팀메이트·공개 파티 동반 근거 20점 및 낮은 순위 보정으로 변경했습니다. 공통 약점 중복은 감점합니다.
- OCR 스테이터스 화면은 슬롯 전체를 한 번에 읽고 각 줄의 실능력치·배분 숫자쌍을 분리합니다. 별명만 표시된 화면은 종을 확정하지 않으므로 능력·도구 화면을 먼저 읽거나 검색으로 종을 선택해야 합니다. 포켓몬을 확정하면 읽지 못한 세팅값을 해당 모드의 최상위 통계값으로 보완하고 화면에 보완 항목을 표시합니다.
- OCR 결과의 도구·특성·성격·기술과 능력 배분은 적용 전에 직접 수정할 수 있습니다. 세팅 편집 검색은 해당 포켓몬의 상세 통계 항목을 채용률순으로 먼저 표시하고, 그 뒤에 챔피언스 마스터 전체 목록을 표시합니다. 상세 통계 미등재 기술·특성은 포켓몬별 사용 가능 여부를 현재 자료만으로 검증할 수 없다고 명시합니다.
- 상세 통계의 기술(최대 4개)·도구·특성·성격·능력 배분을 선택해 기존 슬롯 또는 첫 빈 슬롯에 즉시 적용할 수 있습니다. 직접 설정을 열면 같은 검색형 편집기를 사용합니다.
- 파티 점검에는 선택한 성격·스탯 포인트의 실능력치, 상위 메타 20종의 무보정 S0/S32 스피드 기준, HP×방어/특방 내구 지수와 공격/특공×기술 위력×자속×확인 가능한 도구 보정의 결정력 지수를 표시합니다. 결정력 지수는 상대 내구와 난수 등을 제외하므로 실제 데미지가 아닙니다.
- 스크린샷 입력은 화면 종류 선택을 없애고 여러 장을 한 번에 받습니다. 각 이미지의 모든 슬롯에서 세팅값과 능력 배분을 함께 탐색해 슬롯별로 병합합니다.
- 선택 기술별 데미지는 상위 메타 상대의 `H0·내구0`, `H32·내구0`, `H32·B/D32` 무보정 기준을 비교해 확정/난수 1~3타와 최소~최대 퍼센트를 표시합니다. 챔피언스의 86~100 15난수를 쓰며 명중률과 조건부·필드 보정은 결과와 분리합니다.
- 선출 추천은 화면 해상도나 여백의 고정 픽셀값 대신 좌우 색상 패널과 여섯 행을 먼저 검출합니다. 각 포켓몬 조각의 색상 분포뿐 아니라 배경 분리 실루엣·면적·중심 특징과 오른쪽 타입 아이콘을 함께 비교하며, 후보 버튼과 검색으로 즉시 교정할 수 있습니다.
- `scripts/sync_pokeapi_sprites.py`는 일반색과 이로치 이미지 자산을 모두 저장합니다. 선출 후보는 두 이미지 특징 중 가까운 값을 같은 종으로 합치며, 싱글은 선봉 포함 3마리, 더블은 선봉 2마리와 후발 2마리를 추천합니다.
- 챔피언스 전용 타입 상성표: https://op.gg/ko/pokemon-champions/type-effectiveness . 324개 관계를 파싱하고 champs.pokedb.tokyo의 한카리아스 상세 약점/저항과 교차 확인했습니다. 다른 게임용 데이터는 사용하지 않았습니다.
- 현재 평가는 기본 타입과 선택 기술의 배율만 사용합니다. 메가진화, 특성, 도구, 스피드, 실제 데미지, 변화기 운영은 미반영이므로 확정 카운터/승률로 해석하지 않습니다. 최신 시즌 자동 업데이트가 아니라 M-4 스냅샷에 대한 분석입니다.
