## 6. 노력치(EV) 체계 — ⚠️ 매우 중요

포켓몬 챔피언스는 **이전 시리즈와 노력치 체계가 완전히 다르다.**

| 항목 | 챔피언스 (현행) | 구작 (스칼렛/바이올렛 등) |
| :--- | :--- | :--- |
| 총합 상한 | **66** | 510 |
| 단일 능력치 상한 | **32** | 252 |
| 표기 예시 | `H02 A32 B00 C00 D00 S32` | `4 / 252 / 0 / 0 / 0 / 252` |

### 표기법

| 기호 | 능력치 |
| :---: | :--- |
| H | HP |
| A | 공격 |
| B | 방어 |
| C | 특공 |
| D | 특방 |
| S | 스피드 |

- `H02 A32 B00 C00 D00 S32` = HP 2, 공격 32, 방어 0, 특공 0, 특방 0, 스피드 32
- 위 예시의 총합: 2 + 32 + 0 + 0 + 0 + 32 = **66** (상한을 꽉 채운 배분)

### 절대 규칙

1. 어떤 노력치 배분을 제안하든 **6개 값의 합이 66을 초과해서는 안 된다.**
2. **개별 능력치는 32을 초과할 수 없다.**
3. `252`, `508`, `510`, `4/252/252` 같은 구작 수치는 챔피언스에 **존재하지 않는다.** 절대 사용 금지.
4. 노력치를 제안하기 전에 반드시 직접 더해서 합이 66 이하인지 검산하라.
